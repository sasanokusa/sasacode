# GUIの対応表：Codex・Claude Code・T3 Codeとの比べ

ほかのコーディングエージェントのGUIにあって、sasacodeのGUI（`sasacode-gui`）にないものを洗い出し、足したかどうかを1行ずつ記録する。調べた時点は2026-11-16、足し終えたのは2026-11-17。

- Codex：OpenAIのデスクトップアプリ（ChatGPTデスクトップのCodexモード）。出典は[learn.chatgpt.com/docs](https://learn.chatgpt.com/docs)
- Claude Code：Claudeデスクトップアプリのコードのタブ、VS Codeの拡張、claude.ai/code。出典は[code.claude.com/docs](https://code.claude.com/docs/en/desktop)
- T3 Code：[pingdotgg/t3code](https://github.com/pingdotgg/t3code)（v0.1.9）

状態の意味：

- あり：前からある
- 足した：このブランチ（`gui/parity`）で足した
- 足さない：理由を書く。sasacodeのエージェントやCLIにない機能、新しい依存（crateやシステムライブラリ）が要るもの、GUIの外で済むものなど

表の「C」「CC」「T3」は、その製品にあるもの。

## 会話と一覧

| 機能 | C | CC | T3 | 状態 | メモ |
| --- | --- | --- | --- | --- | --- |
| 複数の会話を同時に走らせる | ○ | ○ | ○ | 足した | 一覧で別の会話を開いても、走っている会話は止まらない。走っている会話には印が付き、終わると未読になる |
| 会話ごとの下書き |  |  | ○ | 足した | 入力欄の中身は会話ごとに残る。送信待ちのメッセージも同じ |
| 名前の変更 | ○ | ○ | ○ | 足した | 一覧の行の鉛筆か`/rename`。名前は`gui.json`に残り、ログは書き換えない |
| ピン留め | ○ | ○ | ○ | 足した | 一覧の行のピンか`/pin`。ピン留めした会話は一覧の上にまとまる |
| アーカイブと、その一覧からの戻し | ○ | ○ | ○ | 足した | 一覧の行の箱か`/archive`。一覧の下の「アーカイブ」から見て戻せる |
| 削除 |  | ○ | ○ | 足さない | ログは`/usage`や`sasacode -r`が読むので消さない。一覧から外すならアーカイブで足りる |
| 未読の印 | ○ | ○ |  | 足した | 裏で終わった会話、承認を待つ会話に印が付く |
| 会話の中身まで検索する | ○ | ○ | ○ | 足した | `⌘K`の検索が、題だけでなくメッセージの本文も探す |
| 前後の会話へ移るキー | ○ | ○ | ○ | 足した | `⌘⇧[`と`⌘⇧]` |
| 新しい窓で開く | ○ | ○ |  | 足した | `⌘⇧N`か`/window`で、今の会話を別の窓で開く。今の窓から少しずらして、前に出して開く |
| 複数のプロジェクトを切り替える | ○ | ○ | ○ | 足した | パレットに会話のあるほかのフォルダが出る。選ぶとその窓が開く |
| ワークツリーで新しい会話を始める | ○ | ○ | ○ | 足した | `/worktree`で、新しいブランチのgit worktreeをsasacodeのホームに作り、その窓を開く |
| クラウド・SSH・スマートフォンからの操作 | ○ | ○ | ○ | 足さない | sasacodeに遠隔で走らせる仕組みがない |
| 予定を組んだ実行（自動化） | ○ | ○ | ○ | 足さない | sasacodeにスケジューラがない |
| 本筋を汚さない脇の質問（`/btw`、`/side`） | ○ | ○ | ○ | 足した | `/btw 質問`。会話を読んで答えるが、ログに残らない（`--no-session`）。道具の承認は自動で断る |

## 入力欄

| 機能 | C | CC | T3 | 状態 | メモ |
| --- | --- | --- | --- | --- | --- |
| `@`でファイルを指定する（候補つき） | ○ | ○ | ○ | 足した | gitが追う（追うはずの）ファイルとフォルダから候補を出す |
| ファイルを名前で探して指定する（`⌘P`） | ○ |  | ○ | 足した | `⌘P`で入力欄に`@`を入れて候補を開く |
| 画像やファイルをドラッグ＆ドロップで添える | ○ | ○ | ○ | 足した | 落としたファイルが`@パス`で入る。画像はCLIの画像プラグインが添える |
| 画像をクリップボードから貼る |  | ○ | ○ | 足した | 文字のないクリップボードで`⌘V`を押すと、画像をPNGでsasacodeのホームの`pasted/`に書き、`@パス`で入れる。読み方はTUIと同じ |
| スラッシュコマンドの候補 | ○ | ○ | ○ | 足した | この窓のコマンド（`/new`、`/btw`、`/find`など16個）。CLIやプラグインのスラッシュコマンドはheadlessでは動かないので出さない |
| `↑`で前の入力を呼び戻す | ○ |  | ○ | 足した | 空の入力欄の1行目で`↑`。TUIと同じ`history.jsonl`を使う |
| 実行中に追加の指示を送る | ○ | ○ | ○ | あり | |
| 送信待ちのメッセージを取り消す・直す |  | ○ | ○ | 足した | 実行の終わりを待つメッセージは取り消して入力欄へ戻せる。もうエージェントに渡したものは戻せない |
| 次の入力の提案 | ○ | ○ | ○ | 足さない | 提案のためにモデルを別に呼ぶことになる。費用がかかり、ローカルモデルでは遅い |
| 音声入力 | ○ | ○ | ○ | 足さない | 音声認識の仕組みが要る |
| Enterで送るか改行するかの設定 | ○ |  | ○ | 足した | 設定の画面で選ぶ。改行にすると`⌘Enter`で送る |

## 会話の表示

| 機能 | C | CC | T3 | 状態 | メモ |
| --- | --- | --- | --- | --- | --- |
| 前のメッセージから分岐する・直して送り直す | ○ | ○ | ○ | 足した | メッセージにポインタを載せて「直して送り直す」。そのメッセージの前までのログを写した新しい会話になり、元の会話は残る。分けるのは会話だけで、ファイルの変更は戻さない |
| 最後の返答をやり直す |  | ○ | ○ | 足した | 最後のメッセージの「やり直す」。同じメッセージを、その前から分岐した会話で送り直す。ファイルの変更は戻さない |
| ファイルの変更を戻す | ○ | ○ | ○ | 足した | gitタブの「取り消す」でファイルをコミットした状態に戻す。sasacodeの`/undo`はheadlessで呼べないので使わない |
| 会話の中を検索する（`⌘F`） | ○ |  | ○ | 足した | `⌘F`。合うやり取りだけに絞って見せる |
| 道具の呼び出しの表示を切り替える |  | ○ | ○ | 足した | 設定の画面か`/steps` |
| 時刻の表示 |  |  | ○ | 足した | メッセージの下に「3分前」のように出る |
| 返答のコピー | ○ | ○ | ○ | あり | |
| 会話をMarkdownで書き出す |  | ○ |  | 足した | `/export`でクリップボードへ写す |
| 数式やMermaidの図を描く | | ○ | ○ | 足さない | icedのMarkdownの描画にない。描画の仕組みを自前で足すことになる |
| サブエージェントの呼び出しの表示 | ○ | ○ | ○ | あり | 呼び出しの中に入れ子で出る |
| 計画（todo）の表示 | ○ | ○ | ○ | あり | インスペクタの計画のタブ |
| 長く続ける目標（`/goal`） | ○ |  | ○ | 足さない | プラグインのスラッシュコマンドはheadlessでは動かない。TUIで使う |
| プランモード | ○ | ○ | ○ | 足さない | sasacodeの権限モードにない（エージェントの機能） |

## 差分とgit

| 機能 | C | CC | T3 | 状態 | メモ |
| --- | --- | --- | --- | --- | --- |
| 道具が変えたファイルの差分 | ○ | ○ | ○ | あり | インスペクタの変更のタブ |
| 作業ツリーの未コミットの差分 | ○ | ○ | ○ | 足した | インスペクタのgitタブ（`⌘5`）。ファイルごとの差分が出る |
| 差分の行にコメントして次のメッセージに添える | ○ | ○ | ○ | 足した | gitタブの差分の行をクリックすると`@パス:行`が入力欄に入る。続けてコメントを書いて送る |
| ハンクやファイルごとのステージ・取り消し | ○ |  |  | 足した | ファイルごとのステージ、外す、取り消す。取り消しは2度押す。ハンクごとはしない |
| コミット・プッシュ・PRの作成 | ○ | ○ | ○ | 足した | gitタブから。何もステージしていなければすべてをコミットする。PRは`gh pr create --fill` |
| ブランチ名の表示とコピー |  | ○ | ○ | 足した | 下の帯にブランチ名が出る。クリックでコピー |
| コミットメッセージやPRの説明の自動生成 | | | ○ | 足さない | モデルを別に呼ぶことになる。会話の中でエージェントに頼めば足りる |
| CIの状態・自動修正・マージ | ○ | ○ | ○ | 足さない | GitHubとの連携を作ることになる。`gh`で足りる |
| PRのレビュー画面 | ○ | | ○ | 足さない | 同上 |

## パネルと道具

| 機能 | C | CC | T3 | 状態 | メモ |
| --- | --- | --- | --- | --- | --- |
| 内蔵のターミナル | ○ | ○ | ○ | 足さない | 端末の表示とPTYに新しいcrateが要る。`/terminal`でOSのターミナルをこのフォルダで開く |
| エディタで開く・Finderで表示する | ○ | ○ | ○ | 足した | 変更・gitのファイルの「エディタで開く」「フォルダで表示」と、`/editor`、`/folder`。エディタはVS Code（`code`）があればそれ |
| ファイルの中身を見る | ○ | ○ | ○ | 足さない | エディタで開けば足りる。差分はインスペクタで見られる |
| 内蔵のブラウザ・開発サーバー | ○ | ○ | ○ | 足さない | ウェブの表示エンジンが要る |
| iOSシミュレータ・Androidエミュレータ | | ○ | ○ | 足さない | 同上。エージェントが操る仕組みも要る |
| コンピュータの操作 | ○ | ○ | | 足さない | sasacodeのエージェントにない |
| プロジェクトのスクリプト（実行ボタン） | ○ |  | ○ | 足さない | エージェントに頼むか、`/terminal`で開いたターミナルで走らせれば足りる |

## 状態と通知

| 機能 | C | CC | T3 | 状態 | メモ |
| --- | --- | --- | --- | --- | --- |
| コンテキストの使用量 | ○ | ○ | ○ | 足した | 下の帯に「コンテキストN%」。CLIがheadlessの最初の行でモデルのコンテキスト長を言うようにした（このブランチのCLIから） |
| 使用量（トークン、費用） | ○ | ○ | ○ | あり | インスペクタの使用量のタブ |
| 終わったとき・承認を待つときの通知 | ○ | ○ | ○ | 足した | 窓が後ろにあるとき、OSの通知で知らせる（macOSはosascript、Linuxはnotify-send）。Windowsでは出さない |
| 実行中はスリープさせない | ○ | ○ |  | 足した | macOSは`caffeinate`、Linuxは`systemd-inhibit`。Windowsではしない |
| 注意が要る会話へ移る | ○ |  | ○ | 足した | `⌘⇧A`で、承認を待つ会話か未読の会話へ移る |

## 操作と設定

| 機能 | C | CC | T3 | 状態 | メモ |
| --- | --- | --- | --- | --- | --- |
| コマンドパレット | ○ | ○ | ○ | 足した | `⌘⇧P`。コマンド、タブ、テーマ、拡大、最近のモデル、ほかのフォルダを探して実行する |
| ショートカットの一覧（`⌘/`） | ○ | ○ |  | 足した | `⌘/`か`/keys` |
| 拡大・縮小（`⌘+`、`⌘-`、`⌘0`） | ○ |  | ○ | 足した | 70%から160%まで。`gui.json`に残る |
| テーマ（ライト・ダーク・システムに合わせる） | ○ | ○ | ○ | 足した | 設定の画面かパレットで選ぶ。前は見出しのボタンでライトとダークを切り替えるだけだった |
| ショートカットの割り当ての変更 | ○ |  | ○ | 足さない | 設定ファイルの形と、入力欄やパレットとの食い違いを見る仕組みが要る。割り当ては一覧（`⌘/`）で見られる |
| 設定の画面 | ○ | ○ | ○ | 足した | `⌘,`。Enterキー、テーマ、表示の大きさ、通知、スリープ、道具の呼び出しの表示 |
| 権限モード・推論の深さの選択 | ○ | ○ | ○ | あり | |
| モデルを一覧から選ぶ | ○ | ○ | ○ | 足した | パレットに、ログに残る最近使ったモデルが出る。プロバイダのモデルの一覧はCLIに問い合わせる口がないので出さない |
| MCP・プラグイン・スキルの管理画面 | ○ | ○ | ○ | 足さない | CLI（`sasacode plugin …`）と設定ファイルで管理する |
| 画面の読み上げ | | ○ | ○ | 足さない | iced 0.14にアクセシビリティの仕組みがない |
| リンクから会話を開く（`codex://`など） | ○ | ○ | ○ | 足さない | OSへのURLスキームの登録が要る。`sasacode-gui --session`で開ける |
| 会話の共有 | ○ | ○ | ○ | 足さない | 共有先のサービスがない |
