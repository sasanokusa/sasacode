# GUIの対応表：Codex・Claude Code・T3 Codeとの比べ

ほかのコーディングエージェントのGUIにあって、sasacodeのGUI（`sasacode-gui`）にないものを洗い出し、足したかどうかを1行ずつ記録する。1回目の洗い出しは2026-11-16、2回目（下の「2回目の洗い出し」）は2026-11-17。

- Codex：OpenAIのデスクトップアプリ（ChatGPTデスクトップのCodexモード）。出典は[learn.chatgpt.com/docs](https://learn.chatgpt.com/docs)
- Claude Code：Claudeデスクトップアプリのコードのタブ、VS Codeの拡張、claude.ai/code。出典は[code.claude.com/docs](https://code.claude.com/docs/en/desktop)
- T3 Code：[pingdotgg/t3code](https://github.com/pingdotgg/t3code)（v0.1.9）

状態の意味：

- あり：前からある
- 足した：`gui/parity`と`gui/parity-all`のブランチで足した
- 一部：足したが、書いた部分が欠けている
- 足さない：理由を書く。sasacodeのエージェントやCLIにない機能、新しい依存（crateやシステムライブラリ）が要るもの、GUIの外で済むものなど

表の「C」「CC」「T3」は、その製品にあるもの。

## 2回目の洗い出し（2026-11-17）

1回目の表のあと、3つの製品の機能を隅から隅まで見直した。2つ以上の製品にあるもの、1つにあるもの、キーの3つに分けて、sasacodeのGUIの今のコード（`gui/parity-all`）と1行ずつ突き合わせた。「一部」の行は、欠けている部分をメモに書いた。

| 機能 | C | CC | T3 | 状態 | メモ |

## 見送ったもの

利用者の判断で、作れるが重いものは数式とMermaidの描画のほかは見送った。

- 内蔵のターミナル、内蔵のブラウザと開発サーバー、iOSシミュレータとAndroidエミュレータ、音声入力、画面の読み上げ
- 重いと判断して見送ったもの：PDFのプレビュー（pdfium）、メニューバー（`muda`）、グローバルなホットキー、ほかのアプリの窓の取り込み、SSH、プルリクエストの画面、ほかのエージェントの会話の取り込み、テーマファイルの読み込み、Dockのバッジ

各社のサービスに結びついたもの（アカウント、クラウドでの実行、スマートフォンからの操作、各社のGitHub連携、公開の仕組み、組織の管理、フィードバック）は対象にしない。コンピュータの操作はsasacodeのエージェントにない。
