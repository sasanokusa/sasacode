# GUIの対応表：Codex・Claude Code・T3 Codeとの比べ

ほかのコーディングエージェントのGUIにあって、sasacodeのGUI（`sasacode-gui`）にないものを洗い出し、足したかどうかを1行ずつ記録する。調べた時点は2026-11-16。

- Codex：OpenAIのデスクトップアプリ（ChatGPTデスクトップのCodexモード）。出典は[learn.chatgpt.com/docs](https://learn.chatgpt.com/docs)
- Claude Code：Claudeデスクトップアプリのコードのタブ、VS Codeの拡張、claude.ai/code。出典は[code.claude.com/docs](https://code.claude.com/docs/en/desktop)
- T3 Code：[pingdotgg/t3code](https://github.com/pingdotgg/t3code)（v0.1.9）

状態の意味：

- あり：前からある
- 足した：このブランチで足した
- 足さない：理由を書く。sasacodeのエージェントやCLIにない機能、新しい依存（crateやシステムライブラリ）が要るもの、GUIの外で済むものなど

表の「C」「CC」「T3」は、その製品にあるもの。
