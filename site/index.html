sasacode

プラグインで組み替えられる、ターミナル向けの小さなコーディングエージェント

インストール

curl -fsSL https://sasanokusa.com/sasacode/install.sh | sh

macOS（Apple Silicon / Intel）と Linux（x64 / arm64、glibc / musl）の単一バイナリを ~/.local/bin/sasacode に置きます。Windows は WSL から使えます。バイナリは GitHub Releases の最新版から取得し、SHA256 を検証します。バージョンを固定するには SASACODE_VERSION=v0.8.0、置き場所を変えるには SASACODE_INSTALL_DIR=… を付けてください。

使い方

# API キーを ~/.sasacode/.env に書く（例）
echo 'ANTHROPIC_API_KEY=sk-...' >> ~/.sasacode/.env

sasacode                          # 対話モード
sasacode -p "テストを直して"         # ヘッドレス
sasacode -m openai/gpt-5.5         # モデルを指定

できること

  • Anthropic / OpenAI（Chat Completions・Responses）/ OpenAI 互換（Ollama、OpenRouter など）のモデル
  • read / write / edit / bash と、4段階の権限モード、セッションの保存・再開・分岐
  • TypeScript プラグイン、MCP サーバー、Agent Skills（SKILL.md）をそのまま利用
  • 同梱プラグイン：AGENTS.md、コンテキスト圧縮、サブエージェント、TODO、Web 取得、browsr
  • 小型モデル向け：壊れたツール呼び出しの修復と、同じ文の繰り返しの抑止
  • /model でプロバイダーのモデル一覧から選べる。~/.sasacode/.env にキーを書くだけで始められる
