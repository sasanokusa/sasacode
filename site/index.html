sasacode

プラグインで組み替えられる、ターミナル向けの小さなコーディングエージェント

  • 単一バイナリ
  • macOS · Linux · WSL
  • Apache-2.0
  • オープンソース
curl -fsSL https://sasanokusa.com/sasacode/install.sh | sh

macOS（Apple Silicon / Intel）と Linux（x64 / arm64、glibc / musl）の単一バイナリを ~/.local/bin/sasacode に置きます。Windows は WSL から使えます。バイナリは GitHub Releases の最新版から取得し、SHA256 を検証します。バージョンを固定するには SASACODE_VERSION=v0.8.0、置き場所を変えるには SASACODE_INSTALL_DIR=… を付けてください。

~/app $ sasacode -p "テストが落ちてる。直して"

できること

  • 好きなモデルでAnthropic、OpenAI（Chat Completions・Responses）、Ollama や OpenRouter などの互換エンドポイント。/model で一覧から選べる
  • 小さなコアread / write / edit / bash と4段階の権限モード。セッションは保存・再開・分岐できる
  • プラグインで組み替えTypeScript プラグイン、MCP サーバー、Agent Skills（SKILL.md）をそのまま使える
  • 同梱プラグインAGENTS.md、コンテキスト圧縮、サブエージェント、TODO、Web 取得、browsr
  • 小型モデルにやさしい壊れたツール呼び出しの修復、同じ文や同じ操作の繰り返しの抑止
  • 安心して任せるシンボリックリンクまで見た権限判定と、プロジェクトのプラグインを動かす前の信頼確認
